# 部署与维护

## 发布结构

这是一个纯静态站点，不需要数据库、账号服务或 Node.js 构建。GitHub Pages 从本仓库 `main` 分支根目录发布，预期地址为 https://shfzhangjian.github.io/edu/ 。所有站内资源采用相对路径，支持项目子路径与离线解压。

```text
index.html                  网站入口（生成文件）
assets/                     发布用样式、脚本、课程数据及第三方库
data/                       六个领域的章节 JSON
src/                        网页源文件、构建与 PDF 排版脚本
downloads/                  六册 PDF、物理衔接课件、完整 ZIP
scripts/                    结构验证与离线打包
 docs/                      使用、教材范围、维护说明
启动学习中心.command        macOS 局域网启动脚本
.nojekyll                   禁用 Jekyll 处理
```

不提交浏览器学习记录、凭据、临时截图、生成的质量检查图片或个人配置。`.gitignore` 已排除这些常见文件。

## GitHub Pages 配置

1. 打开仓库 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 **main**，目录选择 **/(root)**，保存。
4. 在 Pages 设置或 Actions 查看构建结果；构建完成后访问网站。

本项目不需要额外 Actions 工作流。后续推送 `main` 会触发 Pages 更新。公开发布意味着仓库中和网站上的教学资源可被访问；不要上传私人答题记录。

## 修改章节内容

编辑 `data/math.json`、`physics.json`、`chemistry.json`、`biology.json`、`astronomy.json` 或 `coding.json`。字段规范见 `src/content-contract.json`。每章包含标题、知识节、目标、公式、例题、活动、易错点、练习与演示编号。

选择题 `answer` 是从 **0** 开始的正确选项下标；解答题 `answer` 是文字答案，`rubric` 是得分要点。稳定保留章节 ID；改变题目顺序可能改变旧学习记录与题目的对应关系，题库大幅重构时需同步设计记录迁移或版本号更新。

`src/extras.py` 是初始拓展资料生成来源，平时直接维护 JSON，不要无意重跑覆盖人工修改。

```bash
python3 src/build_site.py
python3 scripts/validate.py
```

构建会从 `src` 更新发布文件，并从 `data` 合并生成 `assets/content.js`。请不要只改 `assets`，否则下次构建会覆盖。

## 修改界面与互动

- `src/index.template.html`：入口结构。
- `src/style.css`：桌面、手机、打印样式。
- `src/app.js`：索引、章节、练习、自测、备份。
- `src/widgets.js`：共用演示接口、数学及拓展演示。
- `src/phys-widgets.js`、`src/chem-widgets.js`：物理与化学演示。

修改后重新构建，至少核对受影响页面、滑块端点、单位、公式条件、手机布局和浏览器控制台。选择题自动判定、错题移入移出、进度刷新保留也应检查。自动结构检查不替代教材事实核查或视觉检查。

## 更新 PDF

已发布的 PDF 可直接使用，无需安装排版依赖。重新生成需要 Python 的 `reportlab`、`pypdf`、`Pillow`，以及 Poppler 的 `pdftoppm` 和支持中文的 TrueType 字体。

```bash
python3 -m pip install -r requirements-pdf.txt
# macOS 的默认字体为 Arial Unicode；其他环境指定可用的中文 TTF：
EDU_CJK_FONT=/path/to/chinese-font.ttf python3 src/make_pdfs.py
```

`pdftoppm` 默认从 PATH 查找，也可用环境变量 `EDU_PDFTOPPM` 指定路径。脚本生成 PDF 并输出检查图到忽略的 `qa/` 文件夹。更换字体可能改变分页，需检查中文、上下标、公式与整页排版。若页数变化，请同步更新 README 中的页数。

## 打包与提交

```bash
python3 src/build_site.py
python3 scripts/validate.py
python3 scripts/package.py
git add .
git commit -m "Update teaching resources"
git push origin main
```

ZIP 采用文件白名单，不包含 Git 历史、`qa` 或私人学习记录。ZIP 内为可离线使用的网站、数据、资料、启动脚本与使用文档；源代码以仓库为准。检查页面下载链接和 PDF 内容与网页保持一致。

## 预览、恢复与凭据

在仓库根目录双击启动脚本，或运行 `python3 -m http.server 8080` 本机预览。脚本的局域网模式绑定所有网络接口，仅在需要共享时运行，结束后按 Control+C。

如果更新有误，优先用 `git revert <commit>` 生成恢复提交，再推送；不要强制覆盖远端历史。GitHub 访问令牌应由个人凭据工具管理，不写入代码、README、远端 URL 或网页。已经贴到聊天或公开位置的令牌应撤销并更换；静态网站运行不需要令牌。
