# 使用指南

[返回项目介绍](../README.md) · [打开网站](https://shfzhangjian.github.io/edu/)

## 索引与章节

首页上方的数学、物理、化学卡片进入对应学科；生物、天文和编程在复习拓展区。全部章节索引支持关键词搜索、册次筛选和已完成/未完成筛选。搜索会检查章节标题、标签与知识说明。

每章依次提供“教学讲解”“互动与探究”“巩固练习”“教师备课”。学习目标可勾选；页面底部的“标记本章已学完”更新整体进度。目标勾选与章节完成是两种独立记录。

## 互动演示怎样使用

先阅读演示下方的条件说明，再拖动滑块或切换按钮。每次尽量只改变一个变量，记录变化前后的数值与结论。图像、粒子、轨道、遗传等都包含教学简化，不代表完整真实系统。

例如串联电路保持电源电压不变，增大一个电阻，观察总电流及两个电阻的分压；再切换并联，比较支路电压与电流。实际实验需教师依据器材条件安排，不能把网页数值直接当作真实器材的额定参数。

## 练习、错题与自测

- 选择题：点击选项立即显示反馈和解析；可重新选择。当前答错的题进入错题复练，答对后从待练集合移除。
- 解答题：先在文本框写思路，再展开参考答案与得分要点。选择“已掌握”或“需要再练”，采用自评，不是自动语义评分。
- 错题复练：包含答错的选择题和自评需再练的解答题。修改答案或自评后，可点击“刷新列表”更新可见条目。
- 综合自测：按当前学科随机选最多 12 道选择题，全部作答后提交并查看得分、解析。章节小测按本章题量抽取，通常 4 题。分数只反映本次选题。

## 备份与迁移

侧栏“导出学习记录”会下载 JSON 文件，包含进度、作答、草稿与自评。到新浏览器或新网址后点击“导入学习记录”。导入会合并记录，同名条目采用导入值。建议导入前先备份当前记录。

GitHub Pages、局域网 IP、localhost 与文件直开属于不同访问来源，不会自动共享本地存储。隐私模式、禁用存储或浏览器清理可能使记录无法持久保留。导出的记录请自行保存，不要放入公开仓库。

## 打印和下载

“资料下载”页面可下载整包 ZIP 和 6 册 PDF。教师版有答案；学生版无答案并有作答空白。章节底部可打印学案或无答案练习。生物、天文、编程在下载页按领域打印。

选择 A4、关闭浏览器页眉页脚；需要电子版时在打印窗口选择“另存为 PDF”。PDF 是预先生成的快照：修改网页章节数据后，需要重新生成 PDF 与整包才能保持一致。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 双击 HTML 后空白或样式缺失 | 先完整解压，检查 `assets` 与 `index.html` 是否在同一文件夹；也可用启动脚本通过 HTTP 打开。 |
| macOS 启动脚本提示未找到 Python | 安装 Python 3 后重试，或直接双击 HTML 离线使用。 |
| 手机打不开局域网地址 | 核对是否同一 Wi-Fi、电脑服务是否运行、IP 是否变化；访客 Wi-Fi 或客户端隔离可能阻止设备互访。 |
| 8080 已占用 | 启动脚本自动换端口，以终端显示的完整地址为准。 |
| 学习记录不见了 | 检查是否更换了浏览器或访问地址；导入此前导出的记录。 |
| 3D 不可用 | 检查浏览器硬件加速/WebGL；支持静态参考图，其他教学与练习仍可使用。 |
| 新教材目录不一致 | 按知识点搜索，核对版本说明；本项目采用经典目录，不是新版教材逐页复刻。 |
| GitHub Pages 更新未显示 | 在仓库 Actions / Settings → Pages 检查构建状态，完成后刷新或清除页面缓存。 |
