九年级学习中心 — 离线教学与练习资源

局域网一键启动（macOS）
双击“启动学习中心.command”，浏览器会自动打开，终端窗口会显示本机与局域网地址。
同一 Wi-Fi 下的手机、平板或电脑打开显示的局域网地址即可使用。
默认端口 8080；被占用时自动尝试后续端口。保留启动窗口，按 Control+C 停止。
需要 Python 3；移动资料时请将启动脚本与整个文件夹一起移动。

使用方法
1. 解压整个文件夹，再双击 index.html。请保留 assets 与 downloads 子文件夹。
2. 从课程索引按学科、册次和关键词选择章节。
3. 每章提供教学讲解、互动与探究、巩固练习、教师备课四个入口。
4. 选择题自动反馈；解答题对照参考答案与得分要点自评。错选和需要再练的题自动进入错题复练。
5. 学习进度、草稿及错题保存在浏览器本机。更换电脑或打开方式前，请先在侧栏导出学习记录，在新浏览器导入。
6. 资料下载页提供六册主科 PDF。生物复习、天文和编程拓展可用页面打印功能导出 PDF；每章可单独打印学案与无答案练习。
7. 浏览器打印请选择 A4，关闭浏览器页眉页脚。3D视图需要设备支持 WebGL，不支持时会提供静态参考。

实际收录

化学：人教版经典第1至12单元（12单元）
生物：4个初中知识复习专题
天文：4个科学拓展专题
编程：4个算法与项目专题
合计43章/专题，150节知识讲解，88个分步例题，43项探究活动，258道原创练习（172道选择题，86道解答题）。

版本与范围
按照 AetherViz Master README 支持的数学、物理、化学、生物、天文、编程六个领域制作。主线仅九年级，不是初一至初三三年全科教材。语文、英语、道德与法治、历史、地理未包含在本包。
主科采用已核验的人教社经典公开目录，未宣称2026最新版；新版教材可能合并单元或调整顺序，请以所用教材核对知识点。所有讲解、例题、练习为原创整理，不是官方教材正文或原版课后习题。来源与逐章覆盖清单见“版本与范围”。

实验与模型
优先使用虚拟演示和纸笔探究；实际涉及试剂、加热、用电的活动由教师根据实验条件组织。互动模型的简化、适用条件和单位均在演示下方标注。
