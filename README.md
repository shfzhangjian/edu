# 九年级学习中心 · AetherViz

面向课堂教学与自主复习的中文教育网站。以人教版经典目录组织九年级数学、物理、化学，提供知识讲解、互动演示、分步例题、课堂探究和配套练习。

**网站入口：[shfzhangjian.github.io/edu](https://shfzhangjian.github.io/edu/)**  
**离线使用：[下载整套资料包](downloads/九年级完整学习资料包.zip)**，解压后双击 `index.html`。

> 版本范围：本项目使用已核验的人教社经典目录，不宣称为最新教材版本。新版教材的章节名称、顺序与实践要求可能调整，请按知识点核对。生物为初中复习，天文与编程为拓展；不包含语文、英语、道德与法治、历史、地理。

每章提供四个入口：

- **教学讲解**：学习目标、知识解析、公式及适用条件、分步例题、易错点。
- **互动与探究**：可调参数演示、实验或纸笔活动、记录表、参考结论、模型限制。
- **巩固练习**：172 道选择题自动反馈；86 道解答题提供参考答案、得分要点和自评。
- **教师备课**：课堂组织、板书线索、分层任务、易错诊断和参考答案。

全站支持按学科、册次、关键词和完成状态筛选；支持综合自测、错题复练、进度记录和 JSON 备份导入。数学立体视图支持拖动与三视图切换；缺少 WebGL 时提供静态参考。

## 三种打开方式

### 1. 在线访问

打开 **https://shfzhangjian.github.io/edu/**，无需安装或登录。电脑、平板、手机均可使用。若刚完成更新，等待 Pages 构建结束后刷新页面。

### 2. 离线使用

下载整套 ZIP，解压后双击 `index.html`。保持 `assets/`、`downloads/` 与入口文件的相对位置不变。网页核心教学与互动资源均在本地；“来源”中的外部网站链接需要联网。

### 3. 同一 Wi-Fi / 局域网共享

macOS 双击 **`启动学习中心.command`**。脚本会打开浏览器，并在终端显示当前局域网地址，如 `http://192.168.x.x:8080/index.html`。其他设备连接同一网络后打开该地址。

需要 Python 3。默认端口 8080；被占用时自动尝试后续端口。保留启动窗口，按 **Control+C** 停止服务。若系统询问是否允许传入连接，选择允许。IP 地址可能随网络改变，以每次启动时显示的地址为准。

其他系统也可在项目根目录运行：

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

Windows 可将 `python3` 换为 `py -3`。本机打开 `http://localhost:8080/`；局域网设备使用运行服务电脑的局域网 IP。

## 推荐课堂用法

1. 从索引进入本章，先展示导入问题与学习目标。
2. 讲解一个知识小节，用互动演示改变一个条件，让学生先预测再观察。
3. 分组完成探究记录，讨论结论及模型的适用边界。
4. 使用选择题快速反馈，要求学生说明理由；解答题对照得分要点自评。
5. 标记学习进度，把错题留作课后复练。教师页面的 45 分钟流程是单课时示例，不表示一节课完成一整章。

## 数据与隐私

作答、草稿、学习目标与错题保存在**当前浏览器的 localStorage**，没有账号或云同步。不同设备、浏览器，以及在线网址、`localhost`、局域网 IP、直接打开文件，通常分别保存记录。换入口前请点击侧栏“导出学习记录”，在新入口“导入学习记录”。清除浏览器数据可能删除记录。

本站不发送作答数据到应用后端；在线访问由 GitHub Pages 提供，托管平台可能记录正常访问日志。不要将私人学习记录或访问令牌提交到仓库。

这是无需 npm 安装的静态网站。维护内容后运行：

```bash
python3 src/build_site.py
python3 scripts/validate.py
python3 scripts/package.py
```

确认网页与下载内容一致后，提交并推送 `main`。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 保留静态文件原样服务。
